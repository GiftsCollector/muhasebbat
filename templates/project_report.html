تقارير المشاريع

صافي الربح أو الخسارة = الإيرادات المحصلة − إجمالي التكاليف. قيمة العقد ظاهرة للمقارنة ومش بتتحسب إيراد. المحصّل = سندات التحصيل المسجلة على المشروع + إيراد قيود اليومية. المباشرة = عمالة + مواد + معدات + باطن + عهد + سائقين + قيود المصروف. غير المباشرة = نسبة الإداريات. هامش الربحية = الصافي ÷ المحصّل. نسبة التحصيل = المحصّل ÷ قيمة العقد.
